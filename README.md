## Repository Overview

This repository contains the practical assignments completed as part of the **Web Development & API Integration** internship/academic coursework. The projects demonstrate the implementation of various PHP concepts, client-server communication techniques, data validation methods, document generation, XML data handling, and QR code integration.

Each practical focuses on a specific real-world web development concept and provides hands-on experience with PHP and related technologies.

---

## Practical List

### 1. AJAX Auto Suggest

Developed an AJAX-based student filtering system where users can select a study mode from a dropdown list. Based on the selected mode, the corresponding student records are fetched dynamically and displayed without reloading the page, demonstrating asynchronous client-server communication.

### 2. Regular Expression Validation

Created a registration/login form implementing Regular Expressions (Regex) for validating multiple input fields, including:

* Full Name
* Mobile Number
* Email Address
* Username
* Password
* PAN Card Number
* Aadhaar Card Number

This practical ensures proper input validation and enhances data integrity and security.

### 3. XML Import & Export

Implemented XML data handling using a cricket-themed dataset. The practical demonstrates:

* Exporting structured cricket player data into XML format
* Importing and reading XML data using PHP
* Accessing and displaying nested XML elements

This project showcases data exchange and storage using XML.

### 4. PDF Creation using FPDF

Developed a PDF generation system using the FPDF library. Data is fetched from a database table and dynamically converted into a well-formatted PDF document, demonstrating server-side report generation capabilities.

### 5. QR Code Integration

Implemented QR Code generation using PHP. User information is encoded into a QR Code image, which can be scanned to retrieve the stored details. This practical demonstrates the integration of QR technology into web applications for information sharing and identification purposes.
